# Historical design snapshots

`0.1/` preserves the initial MVP documents and the first BCL/runtime planning document. `0.2/` preserves the integrated portable-BCL architecture and specification before expansion to 21 original CoreLib methods and the logical collector.

Their status statements, counts and relative links describe those historical snapshots, not current compatibility. Current contracts live directly under `docs/`, with the implementation ledger in `docs/compatibility.md`, the observed evidence in `docs/validation-summary.md`, and current research under `docs/research/`.
